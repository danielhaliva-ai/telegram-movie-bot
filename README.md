# telegram-movie-bot

בוט טלגרם פשוט לחיפוש מהיר של סרטים.

## הרצה

1. התקן תלויות:
   ```bash
   pip install -r requirements.txt
   ```
2. הגדר משתנה סביבה:
   ```bash
   export TELEGRAM_BOT_TOKEN="YOUR_TELEGRAM_BOT_TOKEN"
   ```
3. הפעל:
   ```bash
   python movie_bot.py
   ```

## שימוש

- `/start` – הודעת עזרה
- `/movie <שם סרט>` – חיפוש סרט
- אפשר גם פשוט לשלוח שם סרט כהודעה רגילה
